# 第五回 · 名单

## 一、一间过分讲究的屋子

二〇〇九年三月，老太太过生日。一家人在城东一个会所吃饭，摆了三桌。

宝玉喝多了。他本来就不胜酒，被人围着敬了几轮，脸一直红到耳根。散席的时候他站不起来，凤姐就让人把他扶上楼，找间屋子躺一会儿。

扶他上去的人随手推开一扇门，把他放在沙发上，关了灯，出去了。

那间屋子不是客房。那是秦可卿平时用的地方——她在集团挂一个董事的名，不常来，但这一间是给她留着的。屋里有一张很宽的桌子，一把很轻的椅子，墙上挂着一幅画，画底下摆着一个花瓶，插着两支花。灯是暖的。**整间屋子讲究得不太像办公室，倒像有人一直在等谁来。**

他在沙发上睡了两个多钟头。

> **批** — 原著第五回是宝玉在秦可卿房里午睡，入了太虚幻境。我把这一场放在同一个地方、同一个理由上——**这里有个讲究：原著让他"睡在可卿的屋子"，是为了让读者心里存一个疙瘩。** 你后头看见她的结局时，会想起这一间屋子。**这就是伏笔的老写法：不写事，只写一个地方。**

## 二、三点二十

他是被渴醒的。屋里很黑，桌上那台笔记本没关，屏幕亮着。

他坐起来，走过去，本来想找水。屏幕上是一份表格。

文件名是：**人才盘点表_终_勿外传_v3.xls**

表头摆着五列：序号、姓名、部门、岗位、备注。

一共二十七行。他后来数过很多次，记得是二十七行——**二十七个人。** 他一个一个人的往下看。

## 三、备注栏

那份表格的"备注"栏里，写的不是工作。

| 姓名 | 部门 | 备注 |
|---|---|---|
| 王熙凤 | 集团 | 最能干的一个。也最狠。**最后被查的是她。** |
| 贾元春 | 上层关系 | 上去得最快。这个家里，只有她一个关系。**线断了，家就没了。** |
| 贾探春 | 事业部 | 庶出。做得最好，走得最远。 |
| 贾迎春 | — | 老实。嫁错了人。 |
| 贾惜春 | 品牌 | 冷。她是最早走的一个。 |
| 李纨 | 后勤 | 守着一件事，过完一生。 |
| 秦可卿 | 董事 | **早走。没说理由。** |
| 薛宝钗 | 董事 | 这一代里能力最强的一个。**她会嫁给她并不爱的人。** |
| 林黛玉 | 无 | 写得最好。身体最差。没有单位，长期挂靠。 |
| 史湘云 | 市场 | 苦。但她自己不知道。 |
| 妙玉 | 茶室 | 清高。清高的人租房子住。 |
| 香菱 | 后勤 | 学什么都快。命里没给她时间。 |

| 平儿 | 总裁办 | 一辈子在替别人挡事。 |

| 巧姐 | — | 靠刘姥姥。 |
| 贾宝玉 | — | *（空白）* |

他看不懂。他喝的酒还没退干净，眼睛也不太对，只觉得很奇怪——这份表为什么要给每个人写这么一句话？

他又往前翻。前面还有几行，是他没见过的名字。再往下，表格结束了，最后一行是空的，序号停在二十七。

**而"贾宝玉"那一行的备注栏，是空白的。**

## 四、他记住了三句

他想给这张表拍个照。他摸出手机，屏幕黑着——没电。

他在桌前站了一会儿，把记得住的几句话在心里念了两遍。念到第三遍的时候，他忽然发现：**这二十七个人里，每一个人的备注都写好了，只有他自己那一栏，什么都没写。**

他又看了一遍"秦可卿"那一行。

**早走。没说理由。**

——他这时候还不到二十岁，他不懂"早走"是什么意思。

> **批** — 这三句批语是这一回的命门。
>
> **第一：这一份名单就是全书的目录。** 凡是长篇，第五回左右必须放一张"命运总表"——不放，读者读到一半就散了。曹雪芹明白这件事，所以他把它放在一场梦里；我把它放在一份人事档案里。**为什么？因为今天管着人命运的东西，就是一份档案。** 它不问你想干什么，它只登记你能干什么。
>
> **第二：原著里他自己是有判词的**，那三个字（"情不情"之类）是给了答案的。**我把答案抹了。** 二十七个人，二十六个人有备注，只有他那一栏是空的。**一个没有判词的人，比一个有判词的人更惨：他连"命"都没有，只有"不知道"。** 后来他一生都在找那一栏里本该写的那句话——这就是这本小说真正的主线。
>
> **第三：我没有写"他梦见了谁"。** 原著有一整场仙姑、曲子、歌舞。这里只有一台没关的电脑。**神话换成了设备，一点也没有减轻它的可怕**——因为设备不会对你说话，它只是摆在那儿，等你去看。

## 五、第二天早上

第二天早饭，他起晚了。到了桌上，众人已吃了大半。

秦可卿来敬茶。她比他大五岁，穿得整整齐齐，笑着看他，说：

"昨天喝多了吧？在我那屋里睡了一下午——睡得好不好？"

他说：做了个梦。

她笑了笑，说：梦见什么了？

他想了半天，说：忘了。

> **批** — 这一场我写了三天，最后留下的只有这段对话。**全书最凉的地方就是这里**：一个人刚刚看过另一个人的结局，还把它忘了；而那个人就站在他对面，笑着问他睡得好不好。
>
> **注意：他没有在骗她，他是真的忘了。** 这才是我要的。**如果他记得、却选择不说，那是个情节；他忘了，那才是命。**

那天回去以后，他找了张纸，把还记得的几句抄了下来。他认得自己的字，写得很潦草：

> 王熙凤——最后被查的是她。
> 宝钗——会嫁给她并不爱的人。
> 可卿——早走。没说理由。
> 宝玉——（空）

最后一行，他画了一条横线，横线后面什么都没写。这张纸他夹在了一本书里。

**第七十回之后，这张纸他又拿出来过一次。**
