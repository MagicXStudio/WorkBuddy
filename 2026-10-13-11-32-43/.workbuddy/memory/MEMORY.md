# MEMORY.md — 本项目长期约定

## 东坡谈艺录（对话存档）

- **约定（2026-10-14 起）**：与东坡的谈话一律以 Markdown 存档，用户明确要求。
- **位置**：`东坡谈艺录/`（工作区根目录）。
  - `README.md` —— 体例与总目，只增不改。
  - `YYYY-MM-DD.md` —— 一日一档；同日续谈追加于档末，不另开新档。
- **每档写法**：分节编号，一节一题，每节记三样——**问**（用户原话照录）／**答**（要点与关键句，可节略论证但不改结论、不软化判断）／**落点**（可下手的事或立下的约定）。插图以文字或表格留痕。结尾注明未逐字核对版本的引用。
- **执行要求**：每轮实质谈话结束后主动追加存档，不等提醒。

- **卷四前五回（041—045）关键设计**：041 妙玉＝**最后一个还讲究的人**／**外头的杯子是等级、里头的杯子是心事**／"要是我使过的，砸碎了也不给他"（＝她的干净靠"在人身上划一道线"立起来）／立总纲**"讲究，是给有退路的人准备的"**（→112／113 对看）；"那只被搁下的杯"与刘姥姥那一觉并置。042 宝钗"**叫**"黛玉去（"请"是待客、"叫"是叫到跟前）／"**我也看过……后来烧了**"（**"她那一份烧了，对面那个没烧"**）／"我不跟人说"＝**一笔从此计息的账**（→074）／**"低头，但没掏——这不是她硬气，这是她这个人最后的骨头"**。043 凑份子＝**这个家最精密的一件仪器**（"每个数目都不是钱，是一句话"；**"人情不问来路，只问数目"**）／刘姥姥三千块被记进单子／**撮土为香**（祭 032 那个女孩）／小跟班代祷"**他这人，别的本事没有。他记得你。**"（→078）／黛玉借台上那出戏替他说圆（**"天下的水原都是一处的"**，→098 反照）。044 **题眼＝位置**："**最先挨打的从来不是闯祸的人，是最没有位置的人**"／平儿想死之因＝"**被打时没有一个人替你说话**"／宝玉理妆："**'没用'这两个字，有时候是因为那个人不肯把本事用在争上**"。045 燕窝粥＋"**我在这里一日，就与你消遣一日**"（**安慰里藏着告别**）／黛玉剖白"我多心，往日是我错了"／**雨夜渔翁渔婆**："**她说出'我'的那一刹那，用的是'别人'**"／收句"**没有停的那一天**"（→098）。

- **卷四后段（051—055）关键设计**：051 药：庸医→**熟人介绍的私人医生**（三分钟／一张长单／一大包药），立"**门路即围墙**"、"**没有人会去核那张单子，因为核了就得罪一条线**"；宝玉唯一"自己想学"的学问＝认药（"**这一门是替人受用的**"）；晴雯不吃药＝**在算自己值几碗药**；**新立意象组"被搁着的东西"**（墙角那包没吃的药，"事情往往不是被解决掉的，是被搁着搁着，就过去了"）。052 补裘：破了的是**这个家在别人面前说的那句话**；"她不是在补衣服，是在**往回挣她自己那个位置**"；这一夜＝**他一生"善良"的代价**——"**善良是不用出钱的，是要别人出血的**"；结句"**他知道那上面有一个洞。而别人都不知道。**"；埋"**她原本是有人家的**"（→077）。053 祭祖：经济危机第一次落地＝两句对话"**今年确实难**"／"**知道了。先把年过了**"，立"**每一个'过了年再说'的事，后来都没有再说**"；祭祖骨架＝**站位**（"一年里唯一一次像'一个整体'，而它是靠位置捆起来的"）；单立一节"**数缺席**"（"只能隔着几年一回头，发现少了一张脸"）；收句"**账本这个东西最无情的地方是：它从来不喊**"。054 旧套：贾母"破陈腐旧套"翻成**一组创作论**（"**一个故事能被人提前算出来，那它就不是故事了**"／"**编的人没见过**"→"**你写你没见过的东西，读者是能从字缝里看出来的**"／"**缺什么就编什么**"，警告"**如果你不知道自己为什么想写这个，你写出来的就只是别人的套子**"）；**台上骂那种书、台下有人偷看那种书**（承 042）；凤姐救场→通则"**能把场子救回来的人，往往是将来最先被这个家卖掉的人**"；结尾"**他没想明白**"，埋全书最大反讽：**他们全家骂的那种故事，正在写到他们自己家里**（→120）。055 内宅：顶上来的**是一个未出嫁的女儿**（"**她办得好是福气，办不好是她的错，跟这个家没关系**"）；"翻册子"为骨架——"**规矩不是用来管别人的，规矩是用来自保的**"、"**她手里只有册子**"；赵姨娘闹的不是钱，是"**要人认一句'她是我的女儿'**"，母女死结＝**一个要认，一个要避**；"**我舅舅在哪里**"；立"**她越对，她母亲就越疯**"、"**两条路你都得走，而它们正好相反**"、"**一个人越是被夸'懂事'，她心里的账就越是没人替她算**"。
- **卷四后段两处配对机关**：**051／052＝"这个家怎么用人"**（下人病了"先别惊动老太太"／衣服破了全屋不出声、病着的人连夜补）；**053／054＝"这个家怎么瞒自己"**（屋里人笑、墙角算账，数字比去年多；全家在台下骂"那种套子里的故事"）。
- **卷四末（056—060）关键设计**：五回是一条**因果链**（056 划界线→057 暴露开关→058 问"台下是谁"→059 界线的账单→060"说不清"结案）。056 改革：承包＝"**把公家的变成谁的**"（自注以我在西湖拔葑草、分段包给湖畔人家种菱为例）；老先生"**点头、合上本子**"——"**最危险的声音不是反对，是'算了，不说了'**"；"**改革从来不死在反对它的人手里，死在'没有分到'的人手里**"、"**小惠不是善心，是润滑油**"；"**少了三成**"这个干净的数；结尾她在**传了几十年的旧册子上写下第一行**（"先问旧例；无旧例，问道理；道理也没有，就照最不伤人的那条办"，→074 被逐页翻出）。057 试玉：南方来信真、"明年开春就走"是她自己加的；她要验的是"**这家里有没有一个人会为这个姑娘疼一下**"；崩写成"**停**"（"像收音机被拔了插头"），且明写"**这一下不是因为那块玉，只是一句话**"；三套办法共同点"**都要在外面动手，没有人坐下来问一句'你怎么了'**"；"我不走了"与018"别让爸妈知道"并列——"**都不是道理，都是担保；他要的不是水，是一只手**"；"我给你做媒"＝"**一句没有兑现的好意**"；定性"**写'把柄'是怎么长出来的**"。058 真假：**"所有的规矩都是对的，而对的规矩落到人身上，是有形状的"**；"痴理"三句（**接着过／不能丢下不提／忘了她我就不是我了**）——"**往前过和翻掉是两件事**"；台上演夫妻**不点破**；"**那台下这个呢**"＝第三次问"我是谁"，"**他这辈子从来没有'台下'**"；袭人"**演久了，只会忘了自己原来是谁**"。059 吵架：**"所有的怨气都顺着台阶往下流，一直流到最下面那一级；那一级站着的，永远是一个孩子"**；"**从前是大家的**"只让一个孩子说得出口；处理三招——"**不是解决事，是解决人；按得住，就是太平**"；结在**绕开的半步**（"**一个地方真正坏掉，是因为所有人都学会了绕开那半步**"）；"**她画的那几条线，是直的；人走的路，是弯的**"。060 掉包：**"这一回从头到尾没有一个人是坏的"**；"**差不多＝穷人家的通行证，也是穷人家的墓志铭**"；"**钱有账，物有账，人情没有账**"、"**贪可以查，说不清查不了**"；那声"**哦**"＝不出声的暴力；"**这个家判一件事，从来不是看真假，是看谁说得清**"、"**只讲人情、不讲凭据的地方，最后一定是最好的人吃亏**"；"明天再说"接 051；**卷末总批**：卷四"**不写坏人，只写'差不多''明天再说''说两句''算了'**"。
