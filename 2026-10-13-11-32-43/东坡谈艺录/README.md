# 东坡谈艺录 · 存档体例

> 自二〇二六年十月十三日起，凡东坡与「菜鸡坤」的谈话，皆以 Markdown 存档于本目录。

## 体例

- **一日一档**，文件名 `YYYY-MM-DD.md`。同日续谈，追加于当日档末，不另开新档。
- 每档分节编号，一节一题。每节记三样：
  1. **问** —— 用户原话，照录不删。
  2. **答** —— 东坡答语的要点与关键句，可节略长篇论证，但不改结论、不软化判断。
  3. **落点** —— 那一次谈话留下的可下手的事，或立下的约定。
- 文中插图（图示、曲线、对照表）以**文字说明**留痕，必要处附关键数据或表格原文。
- 凡引古籍、旧事，凭记忆处一律标注「未逐字核对版本」，不冒充考据。
- 存档只增不改。若有更正，另起一行注明「补正」，不覆盖原话。
