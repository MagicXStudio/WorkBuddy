# 东坡谈艺录 · 二〇二六年十月十四日

> 与「菜鸡坤」续谈一日，共三节。立了存档制度，把改写稿转成可编辑的 Markdown，然后定下全书一百二十回的工程体例，起了正文五回。

---

## 第一节 建立对话存档制度

**问**：东坡先生，后续的对话，都以 markdown 文档形式存档吧。

**答**：立下的体例三条——

1. **一日一档**，文件名 `YYYY-MM-DD.md`，存于 `东坡谈艺录/`；同日续谈追加于档末，不另开新档。
2. **每节记三样**：问（用户原话照录）／答（要点与关键句，论证可节略，但**不改结论、不软化判断**）／落点（那一次留下的可下手之事，或立下的约定）。
3. **插图以文字或表格留痕**；凡引古籍、旧事，凭记忆处一律注明"未逐字核对版本"，**不冒充考据**。

**补记**：同时追溯补了十月十三日全天八节（见 [`2026-10-13.md`](./2026-10-13.md)），不当成从今天才起记。

**落点**：存档只增不改。若有更正，另起一行注明"补正"，不覆盖原话。往后每轮实质谈话结束即追加，不等提醒。另加一条自律：给自己上锁——**记性好不等于可信。**

## 第二节 改写稿转 Markdown

**问**：把上面改写的红楼梦也转成 markdown 文档形式，后期我再润色并增加配图。

**答**：交给 `石头记2008/石头记2008.md`（v1.0 可编辑稿）。为"润色"与"配图"各留了接口：

- **配图**：正文内埋 **10 处**占位 `![图 NN：…](./images/NN-xxx.png)`，每处附画面建议（如"低机位拍两只手与一条分叉的线，**不要拍脸**"）。文末「附一 · 配图清单」列明编号、位置、画面、文件名——按清单文件名把图丢进 `images/`，正文链接当场生效。另定了一套色调：**冷、旧、少饱和**；全书不出现真正的"红"，例外只有两处：那块玉，与删稿那夜的屏幕光。
- **润色**：夹批统一为 `> **批** —` 引用块，**要删就删整块，别只删一半**（半块夹批最伤气）。标了 3 处 `【待润色】`（元春线 / 妙玉 / "白茫茫"的落点），并注明"你见过的'一个电话'是什么样子"——这一处他写比我写实。

**落点**：两处**缺文**我认了账——「抄检大观园」（晴雯被清退）与「元春回门」只进了年表，未成文。另立一条硬约束：**宝玉与黛玉同岁（1989）**，润色时勿改成姐弟。

## 第三节 完整改写《红楼梦》，一回一档

**问**：按照以上的设定，请完整改写红楼梦，每一回以一个独立的 markdown 文档。

**答**：先说实在话——**一百二十回是一部长篇的工作量，一个晚上写不完，也不该一晚写完。** 硬凑一百二十个文件出来，那不叫改写，叫拆解原著、套上今天的词，润色到明年也没法读。故定**分批推进**：先把骨架立住，再一回一回写；**每轮续写五回**。

**交付结构**

```
石头记2008/
├── README.md        ← 全书体例、关键设定、时间线、推进方式
├── 回目总表.md       ← 120 回总目与进度（■已成文 / □待写）
├── 石头记2008.md     ← 早期样章 v1.0
├── 回/
│   ├── 第001回-遗石.md
│   ├── 第002回-饭局.md
│   ├── 第003回-进府.md
│   ├── 第004回-一份合同.md
│   └── 第005回-名单.md
└── images/
```

**为什么先写前五回**：它是全书的**总纲**——老甄作引、黛玉进府、宝钗入场、一份名单押下所有人的命。这五回立不住，后面一百一十五回都是空的。

**卷一五回各自立了什么**

| 回 | 现代回目 | 立的东西 |
|---|---|---|
| 001 | 遗石 | "石头"换成 1958 年纺织厂的**奠基石**（不会说话，只看着两次开工）；那块玉有了价钱（1980 年工地，八百块）；老甄失女与那张楼道口的纸条 |
| 002 | 饭局 | 母亲/父亲的诀别各一句家常话；**冷子兴改成投行的人**，用尽调口吻把贾家讲一遍；一句总纲："**把那根线抽掉，三个月都撑不住**"；一张被记了名字的餐巾纸 |
| 003 | 进府 | "没有预约"；檀香与速溶咖啡；老太太那把**不肯换的旧藤椅**；**凤姐改写成三个电话**（三分钟安排完一个人）；王夫人的警告缩成四个字"你别理他"；"我见过你——你那篇文章，我转过" |
| 004 | 一份合同 | 十二万的价钱写明；**"葫芦案"长成一份九页的协议**；贾雨村看到卷宗里"左耳垂有一处小坑"那一页——**只写四个字："他翻过去了"**；宝钗定调："**先让他们看见我们家没事**" |
| 005 | 名单 | **太虚幻境＝一台没关的电脑**；表格名"人才盘点表_终_勿外传_v3.xls"；判词全部改写为备注栏短评；**二十七个人都有备注，只有"贾宝玉"那一栏是空白的**；第二天可卿笑着问他睡得好不好，他说"做了个梦……忘了" |

**两处最要紧的改写理由**（批语原文）

- 第四回：**"当代的'葫芦案'不长成贪官的样子，它长成一份九页的协议。"** 且"一写他犹豫，读者就会去评判他；而这件事里真正让人冷的东西，不是他犹豫不犹豫，是这件事可以完全不经过犹豫就办完。"
- 第五回：**"一个没有判词的人，比一个有判词的人更惨：他连'命'都没有，只有'不知道'。后来他一生都在找那一栏里本该写的那句话——这就是这本小说真正的主线。"**

**与原著的分岔（须记）**

1. 不设**前世**（绛珠仙草、神瑛侍者一概不要）；不设"门子""护官符"。
2. **后四十回另有处理**：不沿用"兰桂齐芳、家道复初"。第一百十九回他确实考过了——但这一笔要变个样子：**他考过了一个资格证，然后把证撕了。中与不中，都不是他的出路。**
3. **"白茫茫"不落在雪上**，落在停机页面、解散的群、打不开的链接——雪会化，服务器会重启。**它没有"干净"可言，只有"无法访问"。**
4. 凡引原著处皆凭记忆，**未逐字核对版本**，每条回末注都重申。

**落点**：进度 **5 / 120**。下一轮 **006—010（卷二前五回）**。两处补文不可忘：第七十四回「抄检」与第十八回「回门」。

## 第四节 续写 006—010（卷二前五回）

**问**：继续写 下一轮 006—010回吧。

**答**：卷二前五回已成文（`石头记2008/回/`）。这一轮各回立的东西：

| 回 | 现代回目 | 立的东西 |
|---|---|---|
| 006 | 借钱 | 刘姥姥＝城西刘家的老太太，为**外孙三千块学费**上门；把原著的"连宗"换成"**三十年前借过的三顿饭**"（身份换成恩情，全书的"欠"由此起）；凤姐那句"**别跟人说是我给的**"解作**放债**；袭人一线**一字不写**，只把工资表上她的部门从"园区"改成"**生活**"——"袭人不是一个女人，是一个位置" |
| 007 | 少年 | 送宫花→**一只装了十二份年礼的纸袋**（"顺序即等级"，"最伤人的不是不够，是刚刚好"）；黛玉三个字"**试用的**"；宝玉与秦钟的相认改为**两人同看一块看不懂的奠基石**（接第一回）；埋下暗线：**"他不问答案的那些朋友，一个都没留住"**；贾瑞在此先描一笔 |

| 009 | 学堂 | 家塾→**贾氏青年班**（"这不是一个班，是一张名单"）；"起嫌疑"改为**一条群聊截图**（写在第几个群里变成了什么）；重心**从学生打架挪到停车场里大人吵架**；司机老李一句"**这地方，是贾家的地方**"埋第一百零五回的应；贾瑞第二笔 |
| 010 | 病历 | "全家总动员式看病"——**被当成一件事处理，没有被当成一个人**；张医生五条话含"明年开春再看"的谶；**家属签字栏五个签名、陪诊人一栏空白**（原著所无）；主诉栏下沿一行小字"**不是病，是我自己的事**"（接第五回"早走，没说理由"）；埋编号 **TN-2009-0417**，第一百二十回收 |

**这一轮最得意的手艺**（批语原文）

- 006：**"这个落差，作者一评就俗了。你要学会把两样东西并排放着，然后闭嘴。"**（三千块与那沓钱同放一桌）
- 007：**"写友情，最省力的写法是写两个人合得来；最狠的写法是写两个人合不来的地方也一样。"**
- 008：**"这两个人从来不是情敌，是一道题的两个解。"**
- 009：**"在大人的世界里，一件小事的解决方案，从来不是把事查清楚，是把事压下去。"**
- 010：**"一张表的签名栏，比三页抒情管用。"**

**落点**：进度 **10 / 120**。下一轮 **011—015**（生辰、照镜子、治丧、白事、铁槛寺）。已埋并登记待回收的钉子：**TN-2009-0417**／"这地方是贾家的地方"／"我是什么？"／"别跟人说是我给的"。

| 回 | 回目 | 立的东西 |

| 011 | 生辰 | 求长生＝**信养生大师**，寿宴正主缺席（一把空椅子）；可卿"**你要说那句话，我就得装着我信**"；贾瑞的冒犯搬进**地下车库**；凤姐之恨落在"**位置**"上 |

**三条最要紧的批语**（原文）

- 011：**"凤姐这个人一生只认一样东西：位置。谁给她排错位置，她就跟谁过不去。"**
- 013：**"人一辈子最大的账，都在那个叫'待办'的文件夹里。"** 又："规格不够，名分来凑；名分不够，可以买。"
- 015：**"这本书后面所有的散，都不是从'不知道'开始的，都是从'知道，然后回去睡'开始的。"**

**落点**：进度 **15 / 120**。新埋钉子：**"待办"文件夹**（→107）、**"代收"款与"沁芳"楼**（→107）、**那个号码**（→105 后打不通）、**十一个字**（→114）、**"铁槛·山居"牌子**（→白茫茫）。下一轮 **016—020**。
