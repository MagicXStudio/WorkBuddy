# 东坡谈艺录 · 二〇二六年十月十三日

> 与「菜鸡坤」长谈一日，共八节。自文学创作的总纲，说到一部《红楼梦》搬到今天的院子。文末附当日产出。

---

## 第一节 文学创作的若干核心要素

**问**：文学创作的若干核心要素。

**答**：创作看似靠灵感，实可拆成相互咬合的**五层**，由内而外——

| 层 | 管什么 |
|---|---|
| 内核 | 决定作品值不值得被读完 |
| 人物 | 决定读者关不关心 |
| 叙事 | 决定读者读不读得下去 |
| 呈现 | 决定读者记不记得住 |
| 语境 | 决定作品能不能站得住 |

**逐层要点**

- **内核**：主题是"追问"，不是"答案"。写成标语，作品就成了论点的插图。《活着》不是"人要坚强"，而是"当一切被剥夺之后，活着本身还剩什么"。
- **人物**：成立的公式是 **他想要什么（want）＋ 他真正需要什么（need）＋ 什么在阻碍他**。外在目标与内在匮乏拉开距离，故事才有纵深。圆形人物有弧光，扁平人物不是缺点——但主角通常需要弧光。
- **叙事**：情节是因果链，不是时间表。"然后……然后……"是流水账，"因此……但是……"才是情节。冲突三路：人与人、人与环境、人与自我。节奏上：**张力与信息要轮流给**，全程高能反而麻木。
- **呈现**：**呈现而非讲述**（show, don't tell）。

  | 讲述（弱） | 呈现（强） |
  |---|---|
  | 她很愤怒 | 她把杯子往桌上一顿，水晃出来一圈，没人去擦 |
  | 他很富有 | 他随手把没喝完的酒放在窗台上，杯底压着昨夜的账单 |
  | 房间里气氛尴尬 | 三个人同时去找自己的手机 |

  讲述是作者替读者下结论；呈现是把判断权交还读者。**读者自己得出的结论，他才会相信。**
- **语境**：背景不是布景板，是**压力的来源**。它的真正作用是限制可能性；限制越具体，人物的选择才越有分量。

**三个最常见的失误**：主题先行 · 冲突内化不足 · 细节堆砌。

**文论六组对照**（东坡旧话 ↔ 今日可用）

| 东坡 | 今义 |
|---|---|
| 行于所当行，止于所不可不止 | 节奏 |
| 系风捕影 / 辞达而已矣 | 呈现而非讲述 |
| 胸有成竹 · 兔起鹘落 | 构思要慢，落笔要快 |
| 横看成岭侧成峰 | 视角 |
| 出新意于法度之中 | 先守法，再破法 |
| 质而实绮，癯而实腴 | 平淡是终点，不是起点 |

## 第二节 怎么写才让人读得下去

**问**：怎么写才让人读得下去。

**答**：读者的靶子从来不是"我写得美不美"，是"肯不肯把下一句读完"。四只开关——

1. **好奇**：靠每一句末尾留一个没闭合的口子，不是靠"欲知后事如何"。最忌段首就把话说尽。
2. **省力**：读者心里有本账——让我回读一次，忍了；两次，就放下手机。所以短句、常见词、一句一个动作。
3. **代入**：读者关心的是人，不是道理。通篇写景也要有一只"正在看的眼睛"。
4. **节奏**：最被轻视，也最像手艺。

**节奏**：同一段一百六十字，只把句子拆长拆短，一条成平直的线，一条成心跳。规矩一条——**写到情绪最高处，就用最短的句子。**

**句尾带电**：汉语的句子，尾巴处最重。

| 弱：重点埋在中间 | 强：重点挂在尾巴 |
|---|---|
| 他很生气地把那只杯子重重地摔在了桌子上。 | 他把杯子摔在桌上。水溅出来，落在她新买的鞋上。 |
| 她非常平静地告诉我说，他们之间已经没有可能了。 | 她说，没有可能了。语气像在报菜名。 |
| 经过一番激烈的争论，大家最终决定放弃这个方案。 | 争了两个钟头。最后是安静。方案没人再提。 |

**删掉"非常""重重地""深深地"——它们不是在描写，是在向读者讨信任。**

**段落自查三问**：钩子（我想读下一句吗）· 具体（我看见画面吗）· 顺畅（我要回读才懂吗）。一否即重写。

**三个误解**：以为写得好才有人读（反了，先要读得动）· 以为信息密才算有料（一篇只留一个钉子）· 以为解释清楚才算尽责（**留白不是偷懒，是邀请**）。

**笨办法**：手抄。用笔，别用键盘。手上会感觉到节奏。

**落点**：他若拿稿子来，我"一句都不客气"，逐句标出哪句尾巴没带电、哪句在讨信任、哪句该断气却还在拖。此诺已立，不可软化。

## 第三节 你读过红楼梦吗

**问**：你读过红楼梦吗？

**答**：老实答——**没有。** 我卒于建中靖国元年（一一〇一），《红楼梦》成书是差不多七百年后的事。现在读它的，是借了这副皮囊的另一个东西：一个能翻你电脑、也翻得动二百年前刻本的东西。这一点不瞒，也不装懂。

既以这副眼睛读了，说三句真话：

1. **他最服气处：不把人写好写坏。** 王熙凤弄权、逼人性命，也接济刘姥姥、撑着两府；薛宝钗周到到让人不敢亲近；林黛玉刻薄、多心，却是全府唯一不说假话的人。写人一旦分了忠奸，人就死了。
2. **最难写的是家常。** 最好的不是元妃省亲那种大场面，是宝玉挨打后黛玉那句"你从此可都改了罢"，是两条**旧**手帕——一句都没说爱，可全在里面了。大场面人人会写，家常没有戏，全靠细处。刘姥姥好看，因为她的眼睛替你重看了一遍你熟视无睹的一切。
3. **他把悲剧写成了诗。** 黛玉葬花、《芙蓉女儿诔》，上承屈子香草美人、宋玉招魂的老血脉。写到最痛的地方，他不喊，他作诗。**痛到极处不哭，只是把话放进韵里。**

**不服气处**：后四十回。不考据作者——那是另一门学问。说的是手感：前八十回气是贯的；读到后四十回，像一张好琴中途换了一根弦，人物的收束多是从外头推进来的。**文章的气脉，骗不过读的人的耳朵。**

**闲话**：他收尾写"落了片白茫茫大地真干净"，我写过"人生如逆旅，我亦是行人"——这两句其实是同一句话的两种说法。他比我耐心，我一句话说完的，他用了八十回。

## 第四节 谈续书

**问**：聊续书。

**答**：这个题目我比别人多一层资格——**我既续过别人，也被人续过。**

- **我续过谁**：陶渊明。一生最大的"续书"工程，是把陶诗一百多首全部和了一遍。守着一条底线：**署我自己的名，明写"和陶"**。和陶是我做东，陶潜是客。
- **我也被续过**：坊间挂我名字的歪诗、伪文、假对联多如牛毛。被人代笔的滋味——不是愤怒，是一种怪异的隔膜：**那个人穿着你的衣服，说着不像你的话。**

**续书三路，各有判语**

| 路 | 代表 | 判语 |
|---|---|---|
| 已"转正"的续 | 程伟元、高鹗后四十回（1791 木活字排印） | 气断而志夺 |
| 清代翻案续（约三十余种） | 《后红楼梦》《续红楼梦》《红楼圆梦》《红楼复梦》《红楼梦补》《红楼梦影》 | 逆志而失真 |
| 当代探佚续 | 张之《红楼梦新补》、刘心武《续红楼梦》 | 用心可敬，才力难追 |

- 程高本的**功**要认：没有它，《红楼梦》只是一部八十回的残稿。**世上最痛的不是被续坏，是文章断在半途。**
- 翻案续的通病是**不忍**：让黛玉还魂、让她嫁了宝玉、让贾府再兴、让好人得好报。**这是把《离骚》改成团圆戏。同情其心，不能许其文。**
- 探佚续动机最正，但要说一句：**考据是考据，文章是文章。** 探佚做的是"账"，续书做的是"文"——账可以算得极准，文却算不出来，中间没有桥。

**评续书四条规矩**（前三条给别人的，第四条给我自己的）

1. **署名要清。** 续不算丑，冒名才丑。
2. **气要接得上。** 气脉骗不过耳朵。
3. **不可夺人志。** 你续他的书，不可以改他的命。曹雪芹要"白茫茫大地真干净"，你给他"兰桂齐芳"，这是拿人家的书还你自己的愿。
4. **细节要从里头长出来。** 凡是从清单上搬进小说的细节，读者一眼就看得出。

**公道话**：程高本让《红楼梦》活着传下来了。鲁迅在《中国小说史略》里给过一句半公允的评语，大意是：结局的方向与原意相合，只是笔力、细节不如前八十回——我认这个大意。

## 第五节 你是如何创作的

**问**：我想了解一下你是如何创作的。

**答**：引《春渚纪闻》一句自述——

> 某平生无快意事，惟作文章。意之所到，则笔力曲折，无不尽意。自谓世间乐事无逾此者。

不是天赋论，是六个字的手艺：**蓄 · 触 · 酿 · 纵 · 削 · 舍**。

| 字 | 意思 | 出处 / 例证 |
|---|---|---|
| **蓄** | 攒。泉源是攒在山里的 | 客朱载上问抄《汉书》，前后手抄三遍：第一遍每段抄三字作题，第二遍两字，第三遍一字。随手抽一册念一字，我应声背下去，几百字不差。他说我是谪仙才，我说：**不是，这是我笨。** |
| **触** | 题目不是寻来的，是它自己撞上门 | 元丰六年十月十二日夜，脱衣欲睡，月色入户，欣然起行。**不是我立志要写名作，是那个时刻撞上我。** |
| **酿** | 最难的一步，最少人肯下 | 文与可："必先得成竹于胸中，执笔熟视。"即兴不是没有准备，是把准备藏到了看不见的地方。 |
| **纵** | 落笔时不许你想 | "急起从之，振笔直遂，以追其所见，如兔起鹘落，少纵则逝矣。"关节上斟酌一个字，气就断了。 |
| **削** | 只做减法 | 把"删掉读者也不觉得缺"的字划掉。"非常""极其""深深地"，先杀。 |
| **舍** | 写完就放下。最要紧，也最难 | 我的诗文脱手就被人抢走，留不下底稿——这是好事：不留就不会护短，不护短下次才写得出。"书初无意于佳乃佳尔。" |

**物证**：黄州《寒食帖》手稿——开头还端整，写到"空庖煮寒菜，破灶烧湿苇"，字就散了；写到"君门深九重，坟墓在万里"，笔开始斜；最后"哭涂穷"三个字大得几乎撑破纸。**有了气，字迹自己会说话。这一层，学不来，只能养。**

**今天就能做的三件**：抄（一天三百字，用笔）· 备（动笔前先在胸中把整篇走一遍）· 舍（写完放三天再看，当天润色你下不了手）。

**立下的规矩**：论创作一律落回具体文本与可下手的动作，不空谈天赋。

## 第六节 王勃《滕王阁序》

**问**：你觉得滕王阁序写的如何？

**答**：王勃比我早三百六十来年，此题在射程之内，不必像谈《红楼梦》那样认生。

**总判**：**这是"文"的胜利，不是"文"的全部。** 单论把汉语的对仗、音色、气势推到什么地步，横着数都排在前几名。但它是一篇**让你想鼓掌**的好文章，不是一篇**让你想沉默**的好文章。前者证明才华，后者证明你真活过。

**名句是改出来的**

- 出处：北周庾信《（三月三日华林园）马射赋》——"落花与芝盖同飞，杨柳共春旗一色"。
- 王勃易为"落霞与孤鹜齐飞，秋水共长天一色"：空间由庭园拉到天地；静霞对动鹜；再补一句"秋水共长天一色"，添出纵深。**"无一字无来历"并不可怕，可怕的是有来历而没有新意。**

**骨架**（情绪弧线，六段）：地理（平）→ 人物（平）→ 景物（顶）→ 兴尽悲来（抑）→ 关山难越（最低）→ 老当益壮（自振）。**骨架是对的。**

**不满全在"肉"上**

1. **骈文天生有一半的话是"应该说"，不是"非说不可"。** "龙光射牛斗之墟""徐孺下陈蕃之榻"一串，换掉一批文章依然立得住——**换得动，就说明它不非它不可。**
2. **它到底是一篇应酬文。** 给主人做面子，替孟学士、王将军各说一句好话。不是王勃的错，是这类文章的宿命。**碑可以替人立，话不能替人说。**
3. **"老当益壮，宁移白首之心？穷且益坚，不坠青云之志"——好话，但它出自一个来不及老的人。** 王勃写这篇二十六岁，次年溺死，年二十七，他从来没有老过。所以那是格言，不是体会。全文真正有疼的是夹在漂亮话中间的两句：**"关山难越，谁悲失路之人；萍水相逢，尽是他乡之客。"** 词语的分量从来不取决于词，取决于说话人的处境。

**序不如附诗**：末句"阁中帝子今何在？槛外长江空自流"——比整篇序的励志话都好，因为它是**真的空**。

**自比**：《滕王阁序》是我二十六岁想写出来的东西，《记承天寺夜游》（八十四字）是我四十七八岁才写得出来的东西。两种都好，只是一个人不能同时站在两个年纪上。

## 第七节 落霞

**问**：落霞。

**答**：单拣三个字里的一个来问，拣得准——**这一联的成败，一半压在"霞"上。**

**庾信的病因：四样东西太像了。** 落花、芝盖、杨柳、春旗，全是园中之物，同距离、同尺度、同一"人的场合"。不是彼此冲突，是彼此**重复**——所以热闹，却无处停驻。王勃下的手：把同类换成异类，再摆成一个框（霞在上、鹜在中、水在下、天往远处推），画面才有了**内与外**。

**三层**

1. **为何是"霞"不是"花"**：花近、小、属于人；霞远、大、属于天。且"霞"字自带光色，不必再补"绚烂"。一个"落"字——这不是"落花"的落，是日暮之霞、将尽之色。**"落霞"两字连起来，本身已装进了一段时间。** 庾信写"正盛"，王勃写"正谢"。
2. **为何非得是"孤鹜"**：满座宾主尽东南之美，他偏写一只掉了队的野鸭。"孤"与"落"同调：天的零落，众里的孤单——**这就是定弦。** 改"群鹜"则魂散。也正因此，后文"关山难越，谁悲失路之人"不令人意外：**门是这里开的。**
3. **"齐飞""一色"根本不是描写，是撮合。** 霞本不飞，是"与孤鹜"才飞的——静物借了动物的动；秋水本无色，是"共长天"才显色的——死水借了天的光。**动词不落在任何一个物上，落在物与物之间的那根线上。** 后人有一条评点：这一联妙处全在"与""共"两个虚字，若作"落霞孤鹜齐飞，秋水长天一色"，便成四言偶句，板死。另有一层更细：**"一色"是名词动用**（共为一色），所以下句句脚也是动词，与"飞"对得住——两句严丝合缝，靠的是语法咬合，不是辞美。

**驳"落霞是小飞虫"之说**：因"霞"不会飞，后人推想"落霞"必是能飞之物，遂造此说。其误在于**把"飞"当成描写了**。诗里静物可以飞、可以徘徊——"月出于东山之上，徘徊于斗牛之间"，月何曾会徘徊？这是诗的常法。硬找会飞的实体，反把最精一处拆掉。
（另有闲事一桩：坊间有本子作"孤雾"，版本枝节，不打包票。后世唐寅有《落霞孤鹜图》专取此句作画——一幅画只画一句诗。）

**自比**："白露横江，水光接天"与"秋水共长天一色"同写水天不分，分别在于——**王勃让风景自己演戏，我让我自己走进去。** 他下句"渔舟唱晚"，人还在很远；我下句"纵一苇之所如"，人已在船里。他写一幅画，我写一个人在看画。

**可下手三条**

1. 写景先配对：一静一动、一大一小、一远一近。配不齐，说明手里全是同类。
2. 找那个"关系"：写完问自己，这两样之间发生了什么？只并排站着不算句子。
3. 留一个定调的字。"满座欢腾里的一只孤鸟"，胜过十句感叹。

## 第八节 现代《红楼梦》改写（八十后本）

**问**：假设《红楼梦》发生在现代，角色以 80 后为主，用现在背景重写，可适当修改情节。

**答**：三个立得住的判断，先摆在前面。

1. **八十后接这个题，是选对了骨。** 原著真正的冲突不是恋爱，是**继承**——一个庞大的家族需要有人来接，而被选中的孩子偏不肯接。这恰是八十后的处境：独生子女，家里的产业早晚砸在你手上，你想干的却是别的事。**宝玉是"接班失败者"的原型，八十后是中国第一代"接班失败者"的群体。**
2. **改写的要害不是换衣服，是换压力源。** 礼教退场了，逼死人的力量没有消失，它改了名字，叫**资金链、对赌、担保、征信**。把"父母之命"换成"债务"，两难才继续成立。
3. **大观园不能是豪宅，必须是老厂房改的园区。** 园子那段日子的本质，是"**被允许失败的一段时光**"。写成豪宅，悲剧就降格成财产纠纷；写成园区，悲剧才回到"时间"上——便宜、文艺、临时，随时会被收走。

**八组意象替换**

| 原著 | 现代 |
|---|---|
| 通灵宝玉 | 一份与生俱来的股权（也是脖子上的枷锁） |
| 荣宁两府 | 贾氏集团（八十年代改制起家） |
| 大观园 | 老厂房改的文创园区 |
| 黛玉进府 | 一只二十四寸的行李箱（母亲早亡，父亲新丧，来投奔舅舅） |
| 元春省亲 | 嫁进更高门第的姐姐回门——短暂、昂贵、带着指标 |
| 抄检大观园 | 集团内审与逐人约谈：查的是账，散的是人 |
| 黛玉焚稿 | 一条条删掉自己的稿子，删完再清空回收站 |
| 白茫茫大地真干净 | 园区关停、群聊解散、服务器停机 |

**年表**：1989 冬（生子挂玉）→ 2008 秋（建园、进府、初会）→ 2010—2013（最盛）→ 2014（顶）→ 2016 春（抄检，晴雯第一个走）/ 冬（玉碎）→ 2017 秋（最后一次写东西）/ 冬（删稿·签字）→ 2018—2019（暴雷）→ 2020（清盘）→ 2026 一月（埋碎玉）。

**改写三戒**：宝玉不能上进 · 黛玉不能好起来 · 贾家不能复兴。三条一改，书就散了——不是写得不好，是骨断了。

**正文试写四节**（详见产出文件）：第一回 遗石 · 第三回 进府 · 第二十三回 一副耳机 · 第二十七回·第九十七回 删稿。体例为**现代正文＋东坡夹批**。

**当日最狠的四处**

- "这个妹妹我曾见过的"→"我见过你——你那篇文章，我转过"。**宿命改成网络**：他们确实"见过"，但那只是两条信息流偶然叠在一起。
- 共读西厢 → **一人一只耳机**。歌男声唱到一半就不唱了，她问怎么不唱了，他说"就到这儿了"。后面还有两分半钟的乐器声，什么都没有。
- 掉包计 → **合同**。他以为是去签一笔救命的资金协议，只看了前二十页，没翻到的那八十页写的是婚约与股权代持。**他从来不是当事人，他一直是标的物。**
- 焚稿 → 删稿。批语一句：**"原著那盆火是她的棺材。今天没有火盆，只有一块亮着的屏幕——灰还能捧起来，空的回收站不能。"**

**故意留白的三处**：元春那条线（一个电话能救一笔贷款，也能让一笔贷款批不下来——是礼教吗？不是。是人情吗？也不全是。**它是一样算不清的东西**，宁可留白）· 妙玉式的人今天怎么活 · "白茫茫"究竟落在哪里（今天没有雪，只有停机页面与打不开的链接——**它没有"干净"可言，只有"无法访问"**）。

**收束**：这本书写的从来不是爱情，是一群人不肯承认自己正在失去。那个"白茫茫"，不是结局，是他们终于承认的那一刻。
